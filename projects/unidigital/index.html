Project detail

UniDigital – Digital Student Card

SYSTEM

Project Overview

UniDigital is a digital student card and campus access project designed to improve how student identity and access are managed on campus.

My Role

I contributed to developing a practical student-access solution that focused on streamlined identity validation and a clear user experience for everyday campus operations.

Technologies Used

Java Spring Boot MySQL NFC REST APIs

What I Developed

I helped build a working digital identity concept that supports student profile access, verification workflows, and campus-related functionality in a more efficient and modern format.

Problem

Traditional identification and access systems can be slow, rigid, and harder to manage when institutions need efficient digital workflows.

Solution

The project applies a digital-first approach to student identity, combining a modern interface with backend support to improve access and operational consistency.

Key Features

  • Student profile and identity handling
  • Campus access workflow
  • Structured backend data model
  • Secure, centralised system design

Development Process

The project followed a full-stack approach: designing the system structure, mapping the core workflows, and implementing the digital access functionality with a focus on clarity and reliability.

Challenges

The main challenge was balancing practical campus access functionality with a clean, manageable system design that could support real-world use.

What I Learned

I improved my understanding of backend systems, access workflows, and how digital identity tools can be designed to be both secure and user-friendly.
