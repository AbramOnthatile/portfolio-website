Project detail

AnimeWear / Anime Store

STORE

Project Overview

AnimeWear is an e-commerce application for anime-themed merchandise, built to support store browsing, user interactions, and order-related operations.

My Role

I worked on building a full-stack shopping experience with emphasis on user-facing storefront functionality, product logic, and backend support for store operations.

Technologies Used

React Spring Boot MySQL REST APIs Frontend

What I Developed

I developed the store experience, including product presentation, user interaction flows, cart-related functionality, and data handling for the shopping experience.

Problem

Online stores need a clear, reliable way to present products, manage customer interactions, and support order-related actions without creating a confusing experience.

Solution

The store was designed as a practical full-stack application where customers can browse products, interact with the platform, and complete shopping-related tasks in a clear workflow.

Key Features

  • Product listings and catalog display
  • Shopping cart and purchase flow
  • User accounts and reviews
  • Admin-ready product management structure

Development Process

The project combined frontend design with backend logic so that product data, user actions, and store features could work together in a coherent full-stack system.

Challenges

The biggest challenge was keeping the storefront both attractive and functional while ensuring the flow between the user interface and backend data was consistent.

What I Learned

I strengthened my understanding of end-to-end e-commerce architecture, user flow design, and how full-stack systems support real online shop functionality.
