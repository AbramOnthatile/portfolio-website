Sudoku Game

GAME

Project Overview

Sudoku Game is a Java-based puzzle project built around classic logic and board validation, designed to demonstrate structured game development and problem-solving.

My Role

I contributed to implementing the core puzzle logic, validating board rules, and creating a playable experience with a straightforward interface.

Technologies Used

Java Puzzle Logic Game Development UI Interaction

What I Developed

I developed the sudoku gameplay structure, including number placement rules, validation logic, and a playable board flow for solving the puzzle.

Problem

Games require precise rules and reliable logic to make sure every action is valid and the gameplay remains consistent and fair.

Solution

This project focuses on implementing the game mechanics in a clean and testable way, making sure the puzzle supports valid moves and logical progression.

Key Features

  • Sudoku board and number logic
  • Move validation rules
  • Playable puzzle flow
  • Simple interactive game structure

Development Process

The project involved translating the rules of sudoku into code, building the board mechanics, and ensuring the game logic produced valid and consistent behaviour.

Challenges

Ensuring each move followed the correct row, column and subsection rules was the main challenge in building a reliable puzzle game.

What I Learned

I improved my understanding of game logic, rule validation, and how to translate problem-solving logic into a structured Java application.
