Project detail

UNO Game

GAME

Project Overview

The UNO Game project is a Java-based card game built to replicate familiar gameplay rules and turn-based interactions in a structured form.

My Role

I worked on the game logic and interaction flow, helping shape a playable version of the card-based mechanics and turn progression.

Technologies Used

Java Game Logic Card Mechanics Turn System

What I Developed

I developed the card-game flow, including turn handling, rule enforcement, and the logic needed for smooth, playable interaction between players.

Problem

Card games need consistent game rules and clear turns to feel fair and playable, especially when multiple players or actions are involved.

Solution

The project focuses on implementing the core UNO mechanics in a structured way so turn-based play and card rules remain consistent throughout the game.

Key Features

  • Turn-based gameplay
  • Card matching and validation
  • Game-state progression
  • Playful interactive flow

Development Process

The project involved translating the game’s rules into object-based logic and creating a consistent flow for player turns, card validation, and progression.

Challenges

Ensuring the card rules and turn sequence matched the intended gameplay logic was the main challenge in building a reliable version of the game.

What I Learned

I developed stronger skills in game-state design, rule-driven programming, and building interactive logic that supports a playable experience.
